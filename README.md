# Laravel 12 Practice Project

Repository ini saya buat sebagai media belajar dan eksplorasi Laravel versi terbaru (Laravel 12).  
Tujuan utamanya adalah memperkuat pemahaman saya terhadap arsitektur, fitur, dan pola kerja modern yang digunakan dalam pengembangan aplikasi berbasis Laravel.

## 🎯 Tujuan Pembelajaran
Project ini digunakan untuk:

- Mendalami fitur baru dan perubahan pada Laravel 12.
- Melatih pembuatan komponen, routing, controller, middleware, dan struktur arsitektur yang baik.
- Membiasakan workflow pengembangan profesional menggunakan Git:
  - pembuatan branch untuk setiap fitur
  - push ke remote branch
  - pembuatan Pull Request
  - review & merge ke `main`
- Mencoba integrasi UI seperti Tailwind CSS, komponen Blade, dan layouting modern.

## 🧩 Ruang Lingkup Latihan
Beberapa hal yang dieksplorasi dalam repository ini meliputi:

- Struktur folder Laravel yang diperbarui
- Blade components & layout system
- Manajemen state dan data melalui controller / view-model
- Eksperimen workflow fitur menggunakan Git & GitHub
- Best practice penulisan kode yang rapi dan modular

Project ini akan terus bertambah isinya seiring saya mempelajari lebih banyak fitur.

## 🛠️ Teknologi & Tools
- **Laravel 12**
- **PHP 8+**
- **Composer**
- **Tailwind CSS**
- **Git & GitHub (feature-branch workflow)**

## 🚀 Status
Project bersifat *learning playground* — bukan project produksi.  
Semua fitur di dalamnya dibangun untuk tujuan latihan, percobaan, dan pendalaman konsep Laravel terbaru.
